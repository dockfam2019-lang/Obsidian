# AutoCAD Tracking Plugin

## What It Is
A silent AutoCAD plugin that tracks drafter productivity — time per drawing, lines drawn, commands used, edits, deletions, undos — and uploads data to Google Sheets automatically when a drawing closes.

## Core Value
A drafter opens AutoCAD, works normally, and the employer sees exactly what happened. No manual logging, no behavior change required.
